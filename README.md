# What is TinyNAS

TinyNAS is a small form factor SFF media NAS running a free software called Jellyfin. Jellyfin is a free opensource alternative to streaming apps or whatever you want to call them like Netflix and Disney Plus. This is also a good starting point for beginners who don't know if they will like this because it is a sub $120 build, unlike the best new build I could find on Amazon which is around $250 to $300. Not only this but the build includes how to install all the necessary things so you don't have to find media online yourself and it will autonomously find what you want using Sonarr and Radarr. This also includes simple things on how to upkeep the NAS and a parts list in the BOM.csv file on this GitHub page. I have also tried my best to make this as safe as possible but please if you are concerned about cybersecurity I highly recommend doing a bit of your own research. As of now this is a very safe Jellyfin server but this may change over time.

# Why I made It

Recently I turned my old Chromebook into a Batocera PC and hooked it up to my TV because the Chromebook screen was broken. Now I have over 834 games on it. But I wanted to make it more useful and thats when I came across Kodi Entertainment Center which is built into Batocera. After learning about it I remembered Jellyfin and fell down the rabbit hole of how to connect it to Kodi. That's when I had the idea to make a Kodi entertainment center that connects to Jellyfin so I can play games and watch shows on Batocera making it a two in one system.
